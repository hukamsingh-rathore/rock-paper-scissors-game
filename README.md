
Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript (ES6).

Choose Rock, Paper, or Scissors and play against the computer. The computer makes a random choice for every round, while the game keeps track of both scores.

🌐 Live Demo

Play the game here: https://hukamsingh-rathore.github.io/rock-paper-scissors-game/



🎮 Features

Player vs Computer: Play Rock Paper Scissors against a computer opponent.

Random Computer Choice: The computer randomly selects Rock, Paper, or Scissors for every round.

Win/Lose Detection: Automatically determines the result based on the selected moves.

Draw Detection: Detects when both players choose the same option.

Live Scoreboard: Keeps separate scores for the player and computer.

Selection Highlight: Highlights the option selected by the player.

Result Message: Shows whether you won, lost, or drew the round.

Reset Game: Resets both scores and returns the game to its initial state.

Interactive UI: Includes hover, click, and selection animations.

🛠️ Built With

HTML5 — Structure of the game interface.

CSS3 — Styling, layout, animations, hover effects, and responsive sizing.

JavaScript (ES6) — Random computer choices, game rules, score tracking, DOM manipulation, and event handling.

🧠 How the Game Works

The player selects Rock, Paper, or Scissors.

JavaScript generates a random choice for the computer.

The selected player option is highlighted.

The game compares both choices.

The result message is displayed:

You Win — when the player's choice beats the computer's choice.

You Lose — when the computer's choice beats the player's choice.

Game Draw — when both choices are the same.

The corresponding score is increased.

Press Reset Game to clear the scores and start again.
